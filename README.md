# Allergo
# 🌿 Алерго — персональный дневник аллергика
Веб-приложение (Streamlit) для персонализированного контроля аллергии. Демо-версия доступна по ссылке https://allergoalmaty.streamlit.app. Решение ориентировано для жителей Алматы и прилегающих регионов: учитывает локальные календари аллергенов, зоны риска по райнонам города и типичные для региона перекрёстные реакции. 

## 1. Проблема

- Поллиноз в Алматы — массовое явление: полынь, амброзия и другие сорняки ежегодно вызывают тяжёлые последствия.
- Существующие приложения показывают только общий уровень пыльцы в городе, не учитывая индивидуальную чувствительность.
- Перекрёстная пищевая аллергия (например, полынь → сельдерей и мёд, берёза → яблоко) малоизвестна, и люди едят опасные для себя продукты прямо в сезон цветения.
- Локальных решений под казахстанские аллергены и сезоны почти нет.

## 2. Решение

Единое веб-приложение с тремя модулями:

1. **Дневник симптомов** — фиксация зоны тела, симптома, тяжести (1–5), времени и предполагаемого аллергена.
2. **Навигатор перекрёстной аллергии** — по выбранным аллергенам показывает, какие продукты питания опасны, с указанием частоты реакций и уровня риска; предупреждает, когда сейчас активен сезон конкретного аллергена.
3. **Персональный порог** — по накопленным записям дневника и смоделированной сезонной кривой концентрации пыльцы оценивает уровень пыльцы, при котором у конкретного пользователя начинаются симптомы.

## 3. Архитектура

```
Streamlit UI  →  db.py (SQLite)  →  ml.py (NumPy, персональный порог)
                        ↓
              справочники: аллергены, перекрёстные продукты, симптомы
```
- **Streamlit** - интерфейс пользователя (дневник, аналитика, подписка).
- **SQLite** - хранение записей дневника и настроек пользователя.
- **NumPy** - расчёт персонального порога по данным дневника, без тяжелых ML-зависимостей
- Источник данных о пыльце (KazNARU / UpToDate)  

## 4. Технологии

Python · Streamlit · SQLite · pandas · NumPy 

## 5. Бизнес-модель

**Подписка:**
- Free (0 ₸) - дневник симптомов без ограничений, календарь аллергенов, предварительный просмотр перекрёстной аллергии (4 продукта на аллерген).
- Premium (990 ₸/мес) - полная база перекрёстных продуктов, персональный порог, расширенная аналитика, приоритетные push-уведомления в сезон

**Дополнительные источники дохода:**
- Партнёрство с аптеками - реферальные ссылки на антигистаминные (комиссия с продаж).
- Корпоративные подписки для клинник и аллергологов

**Целевая аудитория:** аллергики 18-50 лет в Алматы, родители детей-аллергиков, врачи-аллергологи для мониторинга пациентов.

## 6. Авторизация 

Простая локальная регистрация/вход (логин + пароль, хеш SHA-256 с солью).
Все записи дневника и тариф (Free/Premium) привязаны к конкретному пользователю, поэтому несколько человек могут пользоваться одним развёрнутым приложением независимо друг от друга.
   
## 7. Запуск локально

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```
## 8. Структура интерфейса MVP

 - [ ] Регистрация и вход по логину/паролю (данные каждого пользователя изолированы).
 - [ ] Дневник симптомов с датой и временем, зоной тела, тяжестью и аллергеном.
 - [ ] Мои аллергены - персональный список аллергенов и календарь пыления по месяцам.
 - [ ] Перекрёстная аллергия - справочник с филтрацией по аллергенам и продуктам.
 - [ ] Аналитика - сводные отчёты и графики (динамика тяжести по дням, частота по зонам тела)
 - [ ] Персональный порог чувствительности.
 - [ ] Подписка - управление тарифом внутри приложения.
